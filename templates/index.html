PROTOCOL MODULE 01

SPF Checker

Sender Policy Framework verifies authorized sending IP addresses.

SPF

How SPF works

SPF uses DNS TXT records to identify which mail servers are authorized to send messages for a domain.

v=spf1 ip4:192.168.1.10 -all
  • ip4: Authorizes a specified IPv4 address or network.
  • -all: Marks other senders as unauthorized.
  • ~all: Produces a softfail for other senders.
PROTOCOL MODULE 02

DKIM Verifier

Cryptographic email signature verification and integrity checking.

DKIM

How DKIM works

DKIM uses a private key to sign selected email headers and the body. A corresponding public key allows receivers to verify the signature.

Private key

Used for signing emails. Keep it secret.

Public key

Published through DNS for signature verification.
